# Sway tools

Utilities specific to the Sway/SwayFX window manager. These are separate from SSH and remote-host utilities in `RemoteTools/`.

## Tools

- [`sway-edge-snap.py`](sway-edge-snap.py) — snap floating windows near screen edges.
- [`sway-swipe-ws`](sway-swipe-ws) — switch between Sway workspaces.
- [`swayshortcuts`](swayshortcuts) — list key bindings from the user's Sway config.
- Per-tool usage guides are in [`docs/`](docs/).

Run the scripts from a Sway/SwayFX session where required. See each guide for dependencies and limitations.
